# Writing Plans

Create an implementation plan that can be executed safely.

The plan must include:

- Target behavior.
- Files or directories likely to change.
- Ordered milestones.
- Validation commands.
- Risks and assumptions.
- Any user decisions still needed.

Keep milestones outcome-oriented. Do not create a plan with tiny mechanical steps.
