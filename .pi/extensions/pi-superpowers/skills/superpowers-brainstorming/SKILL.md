# Brainstorming

Use this before writing code for new features or broad changes.

Process:

1. Restate the user's goal in concrete terms.
2. Ask only the minimum questions needed to remove ambiguity.
3. Identify constraints, risks, and integration points.
4. Offer 2-3 viable approaches with tradeoffs.
5. Recommend one approach.
6. Wait for approval before implementation if the change is invasive.

Do not write code during brainstorming unless the user explicitly asks to proceed.
